# DEPSIM: Registry-Only Dependency Preflight Checker

**Stop `npm install` failures and dependency hell before they happen.**

DEPSIM is a high-performance, registry-only dependency resolution engine. We analyze your `package.json` against the live npm registry in milliseconds—without downloading a single tarball, executing any post-install scripts, or risking supply-chain attacks.

The DEPSIM CLI and deep-resolution engine are currently in private beta. 

**Why use DEPSIM?**
* **Zero Side-Effects:** We never run `npm install` or execute malicious post-install scripts.
* **Lightning Fast:** Async Rust architecture resolves 500+ dependencies in under 2 seconds.
* **Conflict Detection:** Instantly spot React version mismatches, peer-dependency failures, and override conflicts.
