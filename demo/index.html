Installation

🍎 macOS (Intel)

🍎 macOS (Apple Silicon)

🪟 Windows

Download depsim-windows-x64.exe and add to PATH

Documentation

What is DEPSIM?

DEPSIM is a standalone Rust command-line tool that performs registry-only, side-effect-free npm dependency resolution preflight. It reads package.json files, fetches only npm registry metadata, and predicts resolved versions, dependency edges, and conflicts.

⚡ Fast

Resolves 500-package trees in under 2 seconds using parallel async fetching.

🔒 Safe

Never downloads tarballs or executes scripts. Registry metadata only.

🚀 Portable

Single static binary. No Node.js or npm required at runtime.

🎯 Accurate

npm-compatible semver resolution with conflict detection.

Usage

# Analyze package.json in current directory depsim # Analyze specific package.json depsim path/to/package.json # JSON output for CI depsim --json > output.json # Include dev dependencies depsim --dev

What DEPSIM Does NOT Do

  • ❌ Does not install packages
  • ❌ Does not download tarballs
  • ❌ Does not execute scripts
  • ❌ Does not require Node.js/npm
  • ❌ Does not modify your project files
